# 🌐 Portafolio Web

Un sitio web de portafolio personal moderno y responsive, diseñado para presentar proyectos y habilidades de desarrollo web con una experiencia visual dinámica.

## ✨ Características Principales

* **Fondo Canvas Interactivo:** Red de partículas conectadas que reaccionan al movimiento del cursor del usuario en la sección principal (*Hero*).
* **Diseño Fluid & Responsive:** Adaptado para una navegación fluida en dispositivos móviles, tablets y ordenadores de escritorio.
* **Secciones Clave:** Presentación personal, catálogo de proyectos, habilidades técnicas y formulario/enlaces de contacto.
* **Estilo Moderno:** Interfaz limpia con paleta de colores atractiva y efectos visuales interactivos.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del contenido.
* **CSS3:** Estilos personalizados, diseño responsive y animaciones.
* **JavaScript (ES6+):** Renderizado de animación en HTML5 Canvas e interactividad del ratón.
